# 🌐 Personal Portfolio Website

A responsive personal portfolio website built with clean HTML5 and CSS3. Hosted on GitHub Pages.

## 🚀 Live Demo
Check out the live website here: [https://pratyush-mehere.github.io/Portfolio/](https://pratyush-mehere.github.io/Portfolio/)

## 🛠️ Tech Stack
- **HTML5** - Page structure and semantic elements
- **CSS3** - Custom styles, Flexbox layout, CSS variables, and responsiveness

## 📌 Features
- **Responsive Design:** Looks great on mobile, tablet, and desktop displays.
- **Project Cards:** Showcases upcoming web development projects.
- **Contact Links:** Quick access to email and social profiles.
